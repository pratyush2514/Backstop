`execute_query` is the primary tool for submitting SQL to the Backstop gateway. It classifies, gates, snapshots, and executes — returning the full classification metadata alongside the query result.

## Request

<ApiMethod method="POST" path="/" auth="query:execute scope">
  JSON-RPC 2.0 over HTTP POST. Content-Type must be application/json.
</ApiMethod>

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "tools/call",
  "params": {
    "name": "execute_query",
    "arguments": {
      "query": "DELETE FROM sessions WHERE expires_at < NOW()",
      "agent_id": "cursor-local",
      "db_url": "postgresql://postgres:password@localhost:5432/mydb",
      "snapshot_id": "snap_a3f9e2c1"
    }
  }
}
```

### Arguments

<PropertyTable properties={[
  { name: "query", type: "string", required: true, description: "The SQL statement to execute. Single statement only — batched statements are not supported." },
  { name: "agent_id", type: "string", required: true, description: "Identifier for the submitting agent. Used in audit logs and quarantine tracking." },
  { name: "db_url", type: "string", required: false, description: "PostgreSQL connection string. If omitted, uses the gateway's default database URL." },
  { name: "snapshot_id", type: "string", required: false, description: "Snapshot ID to include when resubmitting an approved CRITICAL query. Required for CRITICAL operations after approval." }
]} />

## Response statuses

### executed

Query was classified, policy allowed it, and it executed successfully.

```json
{
  "status": "executed",
  "risk_level": "LOW",
  "result_type": "command",
  "rows_affected": 127,
  "safety_metadata": { ... }
}
```

### blocked

Query was classified and policy blocked it. No execution occurred.

```json
{
  "status": "blocked",
  "risk_level": "CRITICAL",
  "message": "DROP TABLE is blocked by policy",
  "safety_metadata": { ... }
}
```

### approval_required

Query requires operator approval. A snapshot was captured (if CRITICAL). The agent must resubmit with the same `snapshot_id` after approval.

```json
{
  "status": "approval_required",
  "risk_level": "CRITICAL",
  "approval_id": "appr_4f9e2c1a",
  "snapshot_id": "snap_a3f9e2c1",
  "message": "CRITICAL operation requires operator approval. Snapshot captured.",
  "safety_metadata": { ... }
}
```

### denied

An operator explicitly denied the approval. The query will not execute.

```json
{
  "status": "denied",
  "approval_id": "appr_4f9e2c1a",
  "message": "Operator denied execution"
}
```

### failed

Execution failed after approval and gating — a database-level error.

```json
{
  "status": "failed",
  "error": "relation \"users\" does not exist",
  "risk_level": "CRITICAL"
}
```
